# Dean Wilshaw Web Development

## Brand Identity
- **Name / Business:** Dean Wilshaw — Solo React Specialist
- **Tagline:** "Local Solo React Specialist building sub-second web apps."
- **Core Market:** Independent trades and local service businesses in Cheshire & Stoke-on-Trent (Stoke, Crewe, Stafford, Newcastle-under-Lyme, Congleton, Macclesfield).

## Primary Value Proposition
We help local trade businesses stop losing paid ad clicks and Google leads to slow, clunky mobile websites. By engineering sub-second, custom React engines, we deliver instant mobile loading speeds, clean high-end presentation, and frictionless "Tap-to-Call" conversion paths.

## Tech Stack & Delivery
- **Frontend:** React, Vite, Tailwind CSS, TypeScript
- **Infrastructure:** Vercel deployment, GitHub version control
- **Performance:** 95+ PageSpeed Insights scores, sub-second LCP (Largest Contentful Paint)

## Portfolio & Focus Contexts
- **Core Business:** Sub-second commercial web applications and landing engines for local service trades.

- Deployment: Vercel — decided for ease of use and edge performance.
- Aesthetics: High-end, "premium" professional presentation. Clean lines, dark glassmorphic styling, and modern typography.
